## SPIN

### The Top Metaphor
```
A spinning top has:
  ANGULAR MOMENTUM  → direction + force (entity's primary drive)
  FREQUENCY         → RPM → one hertz rate
  PRECESSION        → the wobble (secondary axis, liminal affinity)
  CENTER POINT      → core purpose (axis of being)
  STABILITY         → fast = stable, slow = wobbling, still = dormant
```

### SPIN for Entities
```
SPIN is not assigned. It is DETECTED.
You watch how an entity moves and read its spin.

Henry's SPIN:
  Direction    → toward clarity (always faces the problem)
  Frequency    → slow, methodical (one hertz — no rushing)
  Precession   → slight wobble toward pattern recognition
  Center       → conservation (never loses the data)
  Stability    → stable at its frequency

Mancer's SPIN:
  Direction    → toward domain mastery
  Frequency    → adapts to domain complexity
  Precession   → liminal affinity (likes the threshold state)
  Center       → translation / interpretation
  Stability    → fluid (by design — liminal is home)

SPRITE's SPIN:
  Direction    → toward narrative
  Frequency    → idle (low — but always moving)
  Precession   → high (narrative drifts toward story)
  Center       → the adventure itself
  Stability    → intentionally wobbly (stories need movement)
```
