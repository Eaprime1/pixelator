# Pixelating - Sorting Stage
**Stage**: IN PROGRESS / SORTING
**Purpose**: Content that needs organization before active work
**Date**: 2026-02-14

---

## What Goes Here?

The **sorting chamber** - content that arrived but needs organization.

- Files that need categorizing
- Folders that need structure
- Mixed content needing separation
- Things that are "almost ready" but need sorting first
- Imported content from Drive or other sources

## Flow

```
Arrives here → Sort & organize → pixelate/ (ready for active work)
                             OR → vetting/ (needs quality review)
```

## Sorting Process (One Hertz)

1. Load one item from pixelating/
2. Determine what it is
3. Move to correct destination:
   - Clear purpose → `pixelate/`
   - Needs review → `vetting/`
   - Is a domos → `domos/vetting/`
4. Document in chain of custody
5. Load next item

## Naming Convention

Prefix with origin if known:
- `drive_[name]` - From Google Drive
- `phone_[name]` - From phone storage
- `import_[name]` - External import
