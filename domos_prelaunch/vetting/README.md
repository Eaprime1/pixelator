# Domos Vetting - Submission Folder
**Type**: SUBMISSION GATE (Google Drive Shortcut Compatible)
**Purpose**: Submit domos for vetting review and earn incentives
**Date**: 2026-02-14

---

## This is the Domos Submission Folder

Drop a domos here to submit it for quality vetting.

### On Phone
Place files or folders directly in this directory.

### Via Google Drive
Create a shortcut in Google Drive pointing to this folder.
Submissions via Drive shortcut appear here automatically.

---

## What Happens When You Submit?

1. **File ID logged** - Creates interaction record
2. **Vetting incentive earned** immediately upon submission
3. **Report created** in `reports/` folder
4. **Review begins** - quality check
5. **Decision issued**: APPROVED / NEEDS WORK / REJECTED
6. **Ownership transfers** on approval
7. **Final report** delivered with decision and rewards

---

## Submission Format

Drop a folder or file with:
- Clear name
- README inside (what is this domos?)
- Date

That's all! The vetting system handles the rest.

```
domos/vetting/
├── inbox/          ← DROP SUBMISSIONS HERE
└── reports/        ← REPORTS DELIVERED HERE
```
